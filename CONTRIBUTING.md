# Cómo colaborar

## Cambio pequeño

1. Actualiza tu copia antes de comenzar: `git pull` o **Fetch/Pull origin** en GitHub Desktop.
2. Realiza un solo cambio relacionado.
3. Abre `index.html` y comprueba el resultado.
4. Guarda el cambio con un mensaje claro, por ejemplo: `Ajusta texto de bienvenida`.
5. Sube el commit a GitHub y revisa la página publicada.

## Cambio grande

1. Crea una rama con un nombre descriptivo, por ejemplo `mejora-mapa`.
2. Realiza y prueba el cambio en esa rama.
3. Sube la rama y abre una Pull Request.
4. Pide a la otra colaboradora que la revise.
5. Mezcla la Pull Request con `main` cuando ambas estén de acuerdo.

## Para evitar conflictos

- No editen `index.html` simultáneamente sin coordinarse.
- Hagan `pull` antes de empezar y después de que la otra persona publique.
- Prefieran commits pequeños y descriptivos.
- No suban `afluencia_simple.csv`, carpetas `.venv` ni credenciales.
